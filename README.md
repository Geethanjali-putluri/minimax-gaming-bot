# Minimax Game Playing Bot
**Live Demo:** [minimax-gaming-bot.vercel.app](https://minimax-gaming-bot.vercel.app/)

An interactive AI-based game-playing website that demonstrates how the **Minimax algorithm** can be used to make strategic decisions in board games.

## 📌 Project Overview

The **Minimax Game Playing Bot** allows users to play games against an AI bot while understanding how the bot analyzes possible moves and chooses an optimal decision.

The project includes:

- ❌⭕ **Tic-Tac-Toe**
- 🔴🟡 **Connect Four**
- 🧠 Minimax-based game-playing AI
- 📊 Game statistics and results
- 🔍 Minimax move analysis
- 📚 Academic concepts related to the project
- 🤖 AI/LLM concepts and future enhancements

## 🧠 Minimax Algorithm

Minimax is an **adversarial search algorithm** used in game-playing AI.

The bot considers possible future game states and evaluates them to select a move that maximizes its outcome while considering the opponent's best possible response.

Basic process:

**Current Game State → Generate Possible Moves → Explore Future States → Evaluate States → Choose Best Move**

For Connect Four, a depth-limited Minimax approach can be used because the number of possible game states is much larger than in Tic-Tac-Toe.
